# Changelog
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [v1.4.0] - 2026-01-19
### Changed
- updated data package title to: Macrocystis kelp canopy productivity data from BC Central Coast, v1.4.0
- separated “transect.csv” into 2 csv
- macro_density.csv (only includes plant and frond density data) 
- macro_metrics.csv (includes variables for calculating plant size and changes in productivity)
- updated readme document 

### Renamed
- harvest.csv to macro_harvest.csv
- wet_dry.csv to macro_wetdry.csv

### Added to pre-existing files
- added summer 2022-2015 monitoring data to 
- macro_density.csv
- macro_metrics.csv
- macro_harvest.csv
- added new sites (Ivory_HIRMD, Cape_mark_HIRMD, McMullins_HIRMD, McMullins_north_HIRMD, Goose_HIRMD and Triquetta) to protocols map and table 
- added 2 new variables to both macro_density.csv and macro_metrics.csv, protocols and data_dictionary (Fixed_depth and Transect_length) 
- added new macro_biomass_plot.csv , macro_density.csv and macro_metrics.csv variables to data_dictionary.csv

### Added
- frond_count_biomass_estimates.R - script to calculate biomass estimates based on frond count per plant, creates macro_biomass_plot.csv and plant_weight_site_coeff.csv
- plant_length_biomass_estimates.R - script to calculate biomass estimates based on various methods including cumulative length per plant, creates method comparison figure by sites
- macro_biomass_plot.csv - summary of density and biomass estimates within plot by site and sampling event (biomass estimates are based on frond count to wet weight relationships)
- plant_weight_site_coeff.csv - summary of the coefficients pertaining to  plant morphometrics (frond count or cumulative length) and plant weight by site or region
